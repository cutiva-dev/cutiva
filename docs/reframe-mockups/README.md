# Mockups de Cutiva Reframe

Referencia visual de las piezas del reframe. No son un layout a copiar: el reframe
se integra al editor existente (ver docs/reframe-mvp-spec.md, sección UI/UX).

- playground-actual.png      El editor de Cutiva tal como está hoy. Esta es la base.
- editor-web.source.html     Mockup interactivo del editor de reframe (formato .dc.html:
                             marcado con {{holes}} y una clase Component con la lógica de
                             estados). Léelo como especificación de piezas e interacciones:
                             panel People, recuadro de recorte sobre el source, preview 9:16,
                             layouts por segmento, Camera style y carriles del timeline.
- editor-movil.html          Versión móvil (React Native / Flutter). Abre en el navegador.
- estados-edge-cases.html    Estados especiales: Already vertical, Low quality crop,
                             Bars removed, No faces, Safe zones. Abre en el navegador.

Colores de personas usados en los mockups: A = #FF6A3D (cut), B = #7DB8FF, voz sin cara = #3A3D45.
