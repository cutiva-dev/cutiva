First public release. `@cutiva/core`: the CPF project format, edit commands with undo/redo, and timeline resolution. `@cutiva/web`: import, preview with a frame cache, timeline thumbnails, and MP4 (H.264 + AAC) export with WebCodecs, verified in Chrome on macOS. `@cutiva/react`: `useCutiva`, `useProject`, `usePreview` and `<Timeline>`.
