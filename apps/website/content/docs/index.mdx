description: Cutiva is the open-source video editing SDK for every platform.
---

Cutiva lets you add trimming, splitting, audio and MP4 export to your app without building a video editor from scratch. Edits run on the user's device; no render servers required.

<Callout type="warn" title="Early development">
Cutiva is at v0.0.x. The API will change before v0.1, and the browser engine is tested end to end in Chrome, Edge, Firefox and WebKit on macOS, Windows and Linux. See [browser support](/docs/browser-support). Follow the [roadmap](https://github.com/cutiva-dev/cutiva/blob/main/ROADMAP.md) for status.
</Callout>

## Packages

| Package | Purpose |
| --- | --- |
| `@cutiva/core` | Project format, commands, undo/redo, timeline resolution. Pure TypeScript. |
| `@cutiva/web` | Import, preview and MP4 export in the browser with WebCodecs and Mediabunny. |
| `@cutiva/react` | Hooks and a `<Timeline>` component. |
| `cutiva_core` (Dart) | The core ported to Dart for Flutter. Passes the same conformance fixtures; not on pub.dev yet. |

Flutter preview and export, and the React Native SDK, are planned for the mobile pilot.
