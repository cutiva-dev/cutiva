---
title: Browser support
description: Where Cutiva's web engine works today, and how we know.
---

Cutiva runs in the browser with WebCodecs and Web Audio, so what it can do depends on the browser. This page only marks something as working when a test checks it.

## Tested

End-to-end tests run on every pull request in GitHub's CI. They import a video, edit it, export an MP4, and decode the result to check that every frame and every sound lands within 5 ms of where it belongs. They also check that the preview shows the right frame after seeking and that timeline thumbnails draw.

| Browser | macOS | Windows | Linux |
| --- | --- | --- | --- |
| Chrome | Works · AAC | Works · AAC | Works · **Opus** |
| Edge | Works · AAC | Works · AAC | — |
| Firefox | Works · **Opus** | Works · **Opus**, but video starts one frame (33 ms) late ([#21](https://github.com/cutiva-dev/cutiva/issues/21)) | Works · **Opus** |
| Safari engine (WebKit) | Works · AAC | — | — |

"Works" means preview and export both pass, with H.264 video. The codec after it is the exported audio. Chrome, Firefox and WebKit on macOS must pass before any change merges; the other combinations run on every pull request too.

## Not tested yet

| Browser | Status |
| --- | --- |
| Safari itself (macOS) | Needs testing. The tests use Playwright's WebKit build, which shares Safari's engine but isn't the Safari app. |
| Safari on iPhone and iPad | Needs testing. |
| Chrome on Android | Needs testing. |

## Audio in exported MP4s

Exports use AAC audio where the browser can encode it. Firefox (everywhere) and Chrome on Linux can't, so exports made there use **Opus**. Chrome, Firefox and Edge play Opus in MP4. QuickTime and some phones may not. If a browser can encode neither codec, the export has no audio.

## Check before you export

Ask the engine what the current browser can do, and adapt your UI:

```ts
const caps = await engine.capabilities();

if (!caps.exportMp4) {
  // No H.264 encoder: keep editing and preview, hide export.
} else if (caps.audioCodec === "opus") {
  // Exports will carry Opus audio; warn users who need QuickTime or phone playback.
} else if (caps.audioCodec === null) {
  // Exports will be silent.
}
```

## Known limits

- Exported audio can run up to about 40 ms past the end of the video (codec frame padding).
- The tests don't check preview sound yet. It has only been checked in Chrome, where the audio clock was confirmed running.
